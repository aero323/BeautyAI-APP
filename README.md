# BeautyAI 学员端

BeautyAI 是面向美妆门店 Beauty Advisor（BA）的移动端训练应用原型。它把后台配置的课程、练习、考试、每日打卡和优秀案例采集，组织成 BA 可以直接完成的任务闭环。

BeautyAI 学员端是一个面向门店 BA 的移动端训练应用，当前版本已把后台发布的学习、练习、考试任务接到首页和任务列表，并支持按大区读取 mock 数据。

## 产品流程

```text
选择模拟 BA 身份 → 首页任务收件箱 → 学习 / 练习 / 考试 / 采集 → 本地完成记录 → 首页与任务列表同步更新
```

## 当前能力

- 登录时可选择 mock 为雅加达大区或泗水大区店员。
- 首页展示任务收件箱，支持学习任务、练习任务、考试任务统一管理。
- 课程页展示课件列表、进度、来源筛选和搜索。
- Practice 页支持数字人顾客、场景剧本、金句跟读三类练习。
- 练习任务详情页会按资产类型拆分展示，并支持完成回传。
- 在线考试页支持考试列表、考试说明、答题、结果页和完成记录。
- 个人中心展示学习指标、大区排名和用户信息。
- 首页提供 BA 每日拍照打卡入口，需同时提交妆容照和柜台出样照；提交状态按用户和日期保存在本地。

## 优秀案例采集

- 支持总部视频采集和区域音频采集示例任务。
- 详情页展示采集目标、产品/场景说明、最大时长、文件上限和提交方式。
- 支持现场录制：视频调用摄像头与麦克风，音频调用麦克风。
- 支持本地文件上传；Demo 模式下允许选择任意文件，便于演示完整流程。
- 支持素材预览、重新选择、提交和替换原提交记录。
- 提交成功后显示 BA 个性化赞扬、感谢文案和已完成状态。
- 提交记录与任务状态保存在浏览器 `localStorage` 中。

## 主要路由

| 路径 | 用途 |
| --- | --- |
| `/` | BeautyAI 首页 |
| `/tasks` | 任务收件箱 |
| `/tasks/collection/:missionId` | 优秀案例采集详情 |
| `/tasks/collection/:missionId/success` | 采集成功页 |
| `/daily-checkin` | 每日拍照打卡 |
| `/course` | 课程中心 |
| `/practice` | 练习中心 |
| `/exam` | 考试中心 |
| `/profile` | 学习档案与个人中心 |

## 每日拍照打卡

从首页进入 `/daily-checkin`，拍摄妆容照及柜台出样照后提交。提交后进入 `/daily-checkin/result`，展示打卡成功、两张照片的分数、分项评价与提升建议，点击“完成并返回首页”结束流程。首页会显示今日已完成，再次进入可查看本次 AI 评分。

当前评分为固定 Mock（妆容 94 分、柜台出样 91 分），不调用真实 AI，不上传照片。两张压缩预览按用户保存在当前标签页的 sessionStorage 中，刷新可继续查看当天结果；关闭标签页后清除。打卡完成标记按用户和本地日期保存在 localStorage。直接访问无结果的评分页会返回拍照页。

## 本地运行

1. 安装依赖

```bash
npm install
```

2. 启动开发服务

```bash
npm run dev
```

默认端口是 `3001`。如需使用其他端口：

```bash
npm run dev -- --port 3003
```

桌面浏览器中页面保持移动端手机壳宽度，最大内容宽度为 420px；窄屏设备自动使用满宽布局。

## 说明

- 当前项目使用本地 mock 数据运行，不依赖 Gemini API key。
- 任务、课件、练习、考试、排行榜都以 mock 数据模拟后端返回。
- 这是一个学员端前台项目，重点是把后台的训练对象和任务流呈现出来。
- 优秀案例采集支持浏览器 `MediaRecorder`；无摄像头/麦克风权限时仍可使用上传入口。
- Demo 模式允许任意文件通过上传流程，生产版本应恢复后台配置的格式、大小和时长校验。
- 不会把本地演示文件上传到远程服务。
