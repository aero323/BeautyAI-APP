# J&T Cargo 快递员智慧助手

这是一个面向一线快递员的移动端高保真前端 Mock，覆盖业务异常诊断、企业知识问答、自动培训计划、专项考试、积分与排行榜。

## 核心演示闭环

1. 通过模拟 J&T APP SSO 登录。
2. 收到 PDA 错扫异常通知并进入 AI 诊断。
3. 查看带版本和定位信息的 SOP 引用，跳转模拟业务页面完成重新扫描。
4. 完成事件自动生成的专项课程、场景模拟和考试。
5. 首次考试模拟未通过，完成补训后第二次考试通过。
6. 学习结果回传并生成积分流水。

## 主要能力

- 文本、语音和图片形式的 AI 知识问答 Mock。
- PDA 错扫、签收失败、违规退件和库存异常场景。
- 推荐、课程、SOP、知识四类学习内容。
- PDA 错扫、签收失败和拒收处理等物流场景模拟。
- 填空题、图片题、视频题和分支场景题。
- 部门、区域和全国排行榜及历史结算表现。
- 消息、Push 设置、SSO、深链接和业务回调模拟。
- 身份、任务、考试、消息和积分状态本地持久化。

## 本地运行

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:3001`。可通过 `/?token=mock-sso` 演示 SSO 自动登录。

## 验证

```bash
npm run lint
npm run build
```

本项目不接入真实 AI、OCR、语音、Push、SSO 或物流业务接口，所有响应均为确定性的前端 Mock。
